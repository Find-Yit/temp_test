# 阶段 0D 调研：3DGS→Mesh 的评测维度、Benchmark 与指标落地

**TL;DR**：本项目 4 个场景无 GT mesh，**不建议换 DTU/TnT-GT**（下载+对齐+环境冲突 ≥1.5–2h，挤占训练预算）。几何指标走"**以 3DGS 点云 + COLMAP 稀疏点为双参考的双向点到面距离 + F-score@τ**"，并配"**无参考**的拓扑统计与深度/法向自洽性"；渲染走 3DGS 标准 `llffhold=8` 测试划分。**关键坑：仓库根目录 `metrics.py` 只能评 refined 模型，本项目不跑 refine，必须自写 eval 脚本。**

**事实更正 [DEVIATION-0D-1]**：任务描述中"SuGaR 论文用了 DTU Chamfer"**不成立**。SuGaR(CVPR24) 正文只报 **PSNR/SSIM/LPIPS**，数据集为 Mip-NeRF360(7 场景) + Tanks&Temples(**Truck, Train**) + DeepBlending(**playroom, drjohnson**)，**无任何 Chamfer/DTU 实验**（已核对 arXiv HTML v3 实验节）。用 DTU-Chamfer / TnT-F1 的是 **2DGS、GOF、PGSR、Gaussian Surfels**。好消息：我们手上的 `tandt/{truck,train}` + `db/{playroom,drjohnson}` **恰好就是 SuGaR 论文除 Mip-NeRF360 外的全部评测场景**，渲染指标可与论文表格定性对照（须注明我们是 7k 3DGS + coarse-only，非 30k+refine）。

## 一、学界五个评测维度

| 维度 | 常用指标 | 定义要点 | 需要 GT | 工具 | 代表工作 |
|---|---|---|---|---|---|
| 几何精度 | Chamfer Distance(mm)、Accuracy、Completeness；F-score@τ(Precision/Recall) | CD = ½(mean 预测→GT + mean GT→预测)；F1 = 距离<τ 的双向比例调和平均 | GT 点云/mesh | DTU 官方脚本、TnT `run.py`、open3d | 2DGS、GOF、PGSR、Gaussian Surfels |
| 渲染质量 | PSNR / SSIM / LPIPS(vgg) | 测试视角渲染 vs GT 图 | 测试图像（自带） | `gaussian_splatting/utils` + `lpipsPyTorch` | 全部 |
| 网格质量/拓扑 | 顶点/面数、连通分量数、最大分量占比、非流形边/点、边界边、孔洞数、自交面数、亏格、退化三角形、法向一致性 | 见第四节 | 无 | open3d / trimesh / pymeshlab | Frosting、MILo、SuGaR issues |
| 效率 | 训练/提取墙钟、峰值显存、mesh 文件体积、渲染 FPS | — | 无 | `time`/`nvidia-smi` | SuGaR 主打 |
| 鲁棒性/失败案例 | 漂浮物数量、背景壳伪面、孔洞、超参敏感性曲线 | 定量+定性并举 | 无 | 自制可视化 | 题目 PDF 明确要求 |

## 二、无 GT mesh 时几何指标怎样才公平可信

**分三层，本项目取 L1+L2。**

**L1 伪参考（做）**：mesh ↔ 参考点云的双向点到面/点到点距离。
- 参考 A：**coarse SuGaR 对应的 3DGS 点云**（与被评 mesh 同源，含漂浮物 → 单独用它会"越漂浮越像"）；
- 参考 B：**COLMAP 稀疏点**（truck 136,029 / train 182,686 / playroom 37,005 / drjohnson 80,861 点；干净但稀疏、且本身有外点）。
- **两个参考的结论一致时才敢下结论**——这是本项目几何论证的核心，必须写进报告。

**公平性五条硬约束**（否则数字不可比）：① baseline 与 modified 用**同一份参考点云**（同一个 3DGS ckpt）；② 同一裁剪 bbox（建议 `fg_bbox_factor=1` 的相机 bbox，避免背景壳主导）；③ mesh 采样点数固定（如 200k）且固定 seed；④ **accuracy(mesh→ref) 与 completeness(ref→mesh) 分开报**，只报平均会掩盖"剔点换孔洞"的代价；⑤ 报 mean+median+RMSE+90 分位（Poisson 尾部极重）。
**绝对值无物理意义，只能同场景横向比较。**

**L2 无参考自洽（做）**：拓扑统计；mesh 光栅化深度 vs 3DGS 渲染深度的 L1/AbsRel；mesh 法向图 vs 深度梯度法向的余弦一致性（即 SuGaR `dn_consistency` 的评测版）。

**L3 真 GT（不做，写进 limitation）**：
- **DTU**：需下载官方点云+ObsMask（~5GB），且**必须重训**（我们数据非 DTU），≥2h，直接爆预算。
- **TnT GT**：Truck 属官方 training set，**确有 LiDAR GT**，但需 (a) 官方注册下载 GT+`*_trans.txt` 对齐+`*.json` cropfile，(b) 2DGS 的 `scripts/eval_tnt` 要求 **open3d==0.10.0**，与 SuGaR 所需新版 open3d **直接冲突**（须建第二 venv），(c) 3DGS 版 tandt/truck 与官方 COLMAP 重建坐标系不同，需自行 ICP 对齐。估 1.5–2h 且高失败率。**建议放弃**。
- **Mip-NeRF360**：本身无 GT mesh，换了也解决不了问题。
**结论：不换 benchmark。**

## 三、渲染指标：划分与代码入口

**划分**：`gaussian_splatting/scene/dataset_readers.py:132` `readColmapSceneInfo(..., llffhold=8)`，`idx%8==0` 为 test；SuGaR 用 `GaussianSplattingWrapper(eval_split=True, eval_split_interval=8)`（`sugar_scene/gs_model.py:140-155`）与之一致。必须全程 `--eval true`（`train_full_pipeline.py` 默认 True）。
实际划分：**truck 219/32、train 263/38、playroom 196/29、drjohnson 230/33（训练/测试）**。

**三种渲染对象**：
1. vanilla 3DGS：`gaussian_splatting/render.py --skip_train` → `gaussian_splatting/metrics.py -m <dir>`（现成可用）。
2. **coarse SuGaR**：`torch.load(coarse .pt)` → `SuGaR(..., surface_mesh_to_bind=None)` → `sugar.render_image_gaussian_rasterizer(nerf_cameras=nerfmodel.test_cameras, camera_indices=i, sh_deg=...)`，GT 用 `nerfmodel.get_test_gt_image(i)`（照抄 `metrics.py` 循环即可）。
3. **mesh 本体**：pytorch3d `MeshRenderer/MeshRasterizer` + `AmbientLights`（`metrics.py` 的 `use_uv_texture` 分支是现成模板），顶点色即可，不必做 UV。

**坑（务必写进 SELF_CHECK）**：根目录 `metrics.py` 硬编码加载 `sugarfine_..._{iters}.pt`（refined 模型）与 vanilla **30k/7k 双 ckpt**；本项目不跑 refine、3DGS 只到 7k → **该脚本不能直接跑**，须自写 `scripts/评测_渲染指标.py`，仅复用 `ssim/psnr/lpips` 三个函数。

**随机性**：3DGS `safe_state()` 固定 `seed=0`（`utils/general_utils.py:130-132`）；**SuGaR 各 trainer 无任何 seed 设置**，且 CUDA 光栅化用 atomicAdd 本身不确定。→ 报告中须说明"单次运行差异"，并给出 baseline 自身量级参考（若时间允许跑 2 次 baseline 提取）。

## 四、PDF 点名的 5 个指标如何落地

统一用 **open3d**（SuGaR 本就依赖）+ **trimesh**（可选，纯 Python 轻量），不引入 pymeshlab（其 `get_topological_measures` 跨版本改名，`compute_topological_measures`/`get_topological_measures` 不一致，有踩坑风险）。

```python
import open3d as o3d, numpy as np
m = o3d.io.read_triangle_mesh(mesh_ply); m.remove_unreferenced_vertices()
ref = np.asarray(ref_pcd.points)                      # 3DGS 点云 或 COLMAP 稀疏点
# (2) 点到面距离 = accuracy：参考点 → mesh 表面（精确，无需采样）
sc = o3d.t.geometry.RaycastingScene()
sc.add_triangles(o3d.t.geometry.TriangleMesh.from_legacy(m))
d_ref2mesh = sc.compute_distance(o3d.core.Tensor(ref, o3d.core.float32)).numpy()
# (1) Chamfer：再取反向。mesh 均匀采样 N=200k（固定 seed）→ 最近邻到参考点云
o3d.utility.random.seed(0)            # 老版本无 sample_points_uniformly(seed=) 参数，用全局 seed
ps = m.sample_points_uniformly(number_of_points=200_000)
d_mesh2ref = np.asarray(ps.compute_point_cloud_distance(ref_pcd))
CD = 0.5*(d_mesh2ref.mean() + d_ref2mesh.mean())
# (5a) 几何覆盖率 = Recall@τ；Precision@τ；F-score
tau = 0.01 * cameras_spatial_extent
rec, pre = (d_ref2mesh<tau).mean(), (d_mesh2ref<tau).mean(); F = 2*pre*rec/(pre+rec+1e-12)
# (3) 拓扑统计
V,Fc = len(m.vertices), len(m.triangles)
_,cn,ca = m.cluster_connected_triangles()             # 连通分量数、最大分量面数占比
stats = dict(V=V, F=Fc, comps=len(cn), max_comp_ratio=max(cn)/Fc,
  nonmanifold_edges=len(m.get_non_manifold_edges(allow_boundary_edges=True)),   # 被>2个面共享
  boundary_edges=len(m.get_non_manifold_edges(allow_boundary_edges=False))      # 差集=恰好1个面
                 - len(m.get_non_manifold_edges(allow_boundary_edges=True)),
  nonmanifold_verts=len(m.get_non_manifold_vertices()),
  self_intersect=len(m.get_self_intersecting_triangles()),
  watertight=m.is_watertight(), euler=V-E+Fc)          # 孔洞数≈边界环数，用边界边并查集统计
```
- **(4) 测试视角 PSNR/SSIM(+LPIPS)**：见第三节，`from gaussian_splatting.utils.image_utils import psnr`、`.loss_utils import ssim`、`from gaussian_splatting.lpipsPyTorch import lpips`。
- **(5b) 渲染覆盖率**：pytorch3d 光栅化 mesh 得 `fragments.pix_to_face`，`(pix_to_face>=0).mean()` 即像素覆盖率；与 3DGS 渲染的非背景掩码取比值 → "mesh 漏洞率"，直接量化"边界完整性/孔洞"这一动机。
- **孔洞数**：open3d 无现成接口 → 用边界边（只属于 1 个面的边）做并查集数环数；或 trimesh `mesh.outline().entities` 数量。

## 五、推荐方案表与"6 小时必做最小集合"

| # | 维度 | 指标 | GT/参考 | 工具 | 代价(min) | 优先级 |
|---|---|---|---|---|---|---|
| M1 | 渲染 | test PSNR/SSIM/LPIPS（3DGS-7k、coarse SuGaR） | 测试图像 | 自写脚本+3DGS utils | 40（含首次 LPIPS 权重下载） | **必做** |
| M2 | 几何 | 双向点到面距离 mean/median/RMSE/P90 + F-score@τ（参考 A 与 B 各一份） | 3DGS 点云、COLMAP 稀疏点 | open3d | 40 | **必做** |
| M3 | 拓扑 | V/F/连通分量/最大分量占比/非流形边/边界边/孔洞/自交 | 无 | open3d(+trimesh) | 25 | **必做** |
| M4 | 渲染/覆盖 | 渲染覆盖率、mesh 漏洞率 | 3DGS 渲染掩码 | pytorch3d | 25 | **必做** |
| M5 | 效率 | 各阶段墙钟、峰值显存、顶点/面数、文件体积 | 无 | time/nvidia-smi | 10 | **必做** |
| M6 | 可视化 | baseline vs modified 的 mesh 截图 + 误差热图 + 渲染对比 | — | open3d/matplotlib | 30 | **必做**（PDF 强制） |
| O1 | 几何自洽 | mesh 深度 vs 3DGS 深度 AbsRel；法向余弦一致性 | 无 | pytorch3d | 30 | 可选 |
| O2 | 鲁棒性 | 超参 τ 敏感性曲线（3 取值 × M2/M3） | — | 复用 | 20 | 可选（强烈建议，PDF 要求消融） |
| O3 | 真 GT | TnT-Truck F-score | TnT GT | 第二 venv | 90–120 | **不做** |
| O4 | 真 GT | DTU CD | DTU | 需重训 | 120+ | **不做** |

**6 小时必做最小集合 = M1–M6**，覆盖 PDF 全部点名指标（Chamfer ✓、点到面 ✓、拓扑 ✓、PSNR/SSIM ✓、覆盖率 ✓），估计总实现+运行约 **2.5–3h**（其中脚本开发 ~1h，可与训练并行）。若时间紧，M1 可只留 PSNR/SSIM（跳过 LPIPS 权重下载），M4 降级为只报渲染覆盖率。

## 图 B：多视角深度一致性判据示意

### 整体布局

画一个中心点 **p**（表面采样点），周围环绕 K 个相机（用小相机图标表示）。对每个相机画一条投影连线。

### 判据逻辑（在图旁用公式/图例说明）

对表面点 p 投影到相机 c：

1. 计算点 p 在相机 c 坐标系下的深度 **z_p**
2. 在相机 c 的渲染深度图上查该投影像素的深度 **z_map**
3. 三种判定：
   - **一致票**（绿色 `#27AE60`）：`|z_p − z_map| < τ · z_map`（点与渲染表面深度吻合）
   - **空域冲突票**（红色 `#E74C3C`）：`z_p < z_map − τ · z_map`（点浮在渲染表面之前 = 漂浮点）
   - **被遮挡 / 不计票**（灰色 `#B0B0B0`）：`z_p > z_map + τ · z_map`（点在渲染表面之后，被遮挡）

保留条件：**一致票 >= k** 且 **冲突票 <= v**

### 两个示例（并排）

**示例 1：真实表面点（保留）**
- 一个位于物体表面上的点 p（绿色实心圆）
- 5 个相机中有 4 个给出绿色一致票（投影深度与渲染深度吻合），1 个灰色被遮挡不计票
- 结论：一致票 = 4 >= k=2，冲突票 = 0 <= v=1 → **保留** ✓

**示例 2：漂浮点（剔除）**
- 一个悬浮在空中的点 p（红色空心圆）
- 5 个相机中：1 个绿色（恰好是采样该点的那个视角，自洽），3 个红色空域冲突（该点浮在其他视角的渲染表面之前），1 个灰色被遮挡
- 结论：一致票 = 1 < k=2 → **剔除** ✗

### 图例

在图 B 底部画一个小图例条：
- 绿色圆 = 一致票（深度吻合）
- 红色圆 = 空域冲突票（漂浮）
- 灰色圆 = 被遮挡（不计票）
